# Случайные Бедствия: Влад Эдишн

Мод для **Minecraft 1.21.1 / NeoForge**. Каждые 8–15 минут в мире случается бедствие. Бедствия не накладываются друг на друга: новое начинается только после окончания предыдущего. Исключение — «Двойное бедствие», о котором всегда предупреждают заранее.

## Сборка

1. Установи **JDK 21** (например, Temurin 21).
2. В папке проекта выполни:
   - Windows: `gradlew.bat build`
   - Linux/macOS: `./gradlew build`
3. Готовый мод: `build/libs/vladdisasters-1.0.0.jar`.
4. Положи jar в папку `mods` **у всех игроков и на сервере** (если играете через сервер).

Первая сборка качает Minecraft и NeoForge, это займёт несколько минут.
Проверить в игре без установки: `gradlew runClient`.

## Бедствия

**Обычные** (начинаются сразу):

| Бедствие | Что происходит |
|---|---|
| Бомбардировка | С неба падает динамит и взрывается при ударе |
| Землетрясение | Тряска экрана, трещины в земле (иногда с лавой), блоки взлетают |
| Метеоритный дождь | Огненные глыбы падают под углом и взрываются |
| Пришествие Мамки Влада | Огромное рыжее существо пожирает блоки кусками 7×7, орёт и рычит |
| Кислотный дождь | Жжёт игроков и мобов под открытым небом, разъедает шлем, траву, листву и посевы |
| Извержение вулкана | Ближайший вулкан извергается: лавовые бомбы, потоки лавы, пепел |
| Суперметель | Видимость ~7 блоков, температура тела падает, вода замерзает. Спасает огонь рядом, укрытие или кожаная броня |
| Торнадо | Воронка ходит по миру, засасывает существ и вырывает блоки |
| Засуха | Вода опускается на 2 блока, вокруг распространяется пустыня, растения гибнут |

**Редкие** (за 30 секунд — сирена и предупреждение):

| Бедствие | Что происходит |
|---|---|
| Цунами | Стена воды 15 блоков проходит через местность. После волны вода не остаётся |
| Атомная бомба | Боеголовка, вспышка, кратер ~70 блоков, грибовидное облако. Затем **ядерная зима на 30 минут**: холод, серый туман, радиация у эпицентра |
| Гига-Астероид | Пролетает над головой и врезается в землю: кратер, ударная волна, огненные обломки |
| Чёрная дыра | Растёт в небе, затягивает всё вокруг, через минуту схлопывается |

**Двойное бедствие** — два обычных бедствия сразу, с предупреждением за 20 секунд (несовместимые пары вроде «засуха + метель» не выпадают).

## Предметы

- **Идентификатор бедствий** — пока лежит в инвентаре, над хотбаром видно текущее бедствие и сколько осталось. Крафт: редстоун сверху, железо–компас–железо, стеклянная панель снизу. Также встречается в бункере.
- **Кусок колбасы** — ПКМ призывает Маму Влада на 120 секунд, она сражается за тебя. Крафт: 2 жареные свинины + жареная говядина + нитка. Падает с Мамы Влада, лежит в её доме и в бункере.

## Постройки

- **Вулкан** — генерируется вместе с миром, большой (радиус ~70, высота ~80 блоков, кратер с лавой). Найти: `/locate structure vladdisasters:volcano`.
- **Дом Мамы Влада** — с кухней, огромной кроватью и сундуками с колбасой. С шансом 15% Мама дома — она слабее, чем во время бедствия. `/locate structure vladdisasters:mama_house`.
- **Бункер** — около 150 блоков от спавна, создаётся при первом запуске мира. Стены из обсидиана, бедствия его не ломают. Внутри кровати, сундуки с припасами.
- **Церковь имени Давида Икоева** — статуя Давида, алтарь, скамьи, колокольня, книга заповедей. Внутри повышенный шанс скримера. `/locate structure vladdisasters:church`.

## Скример

Картинка из `textures/gui/screamer.png` на весь экран + громкий резкий звук. Вылезает у каждого игрока минимум раз в 5–15 минут, а в церкви ещё и с небольшим шансом в любой момент.

## Команды (нужны права оператора)

```
/disasters start <бедствие> [true]   — запустить (true = с предупреждением)
/disasters double <a> <b>             — двойное бедствие
/disasters stop                        — остановить всё
/disasters status                      — что идёт и когда следующее
/disasters list                        — список бедствий
/disasters next <секунды>              — через сколько следующее
/disasters interval <мин> <макс>       — интервал в минутах
/disasters auto true|false             — включить/выключить случайные бедствия
/disasters screamer now|all|on|off     — скример
/disasters bunker                      — координаты бункера
```

Имена бедствий: `bombardment, earthquake, meteor_shower, mama_vlad, acid_rain, volcano, blizzard, tornado, drought, tsunami, nuke, giga_asteroid, black_hole, nuclear_winter`.

## Заметки

- Вулканы, дома и церкви появляются только в **новых чанках**, поэтому лучше создать новый мир.
- Бедствия разрушают мир по-настоящему. Мама Влада ест блоки только при включённом `mobGriefing`.
- Текстуры и звуки пересобираются скриптом `tools/gen_assets.py` (нужны Python, Pillow, numpy и ffmpeg): `python3 tools/gen_assets.py путь/к/картинке.jpg`.
